# lironson.github.io

My personal site, served by GitHub Pages at https://lironson.github.io.

## Brand
The whole brand (fonts, colours, sizes, spacing) is in [`brand.css`](brand.css), with comments. Edit the values there.

- To use it on any page: `<link rel="stylesheet" href="https://lironson.github.io/brand.css">`
- To use the Claude Code brand agents in every project, copy `.claude/agents/brand-*.md` into `~/.claude/agents/`.
