# lironson.github.io

My personal site, served by GitHub Pages at https://lironson.github.io.

Plain HTML and CSS with no build step. Edit `index.html` and `style.css`, push to `main`, and the site updates within a minute or two.

## Adding a project

Copy one of the `<article class="project">` blocks in `index.html`, then change the title, description, tags and links.

## Preview locally

```sh
python3 -m http.server
```

Then open http://localhost:8000.
